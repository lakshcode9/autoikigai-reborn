- **Spacing:** Section padding patterns, card gaps, container max-widths
- **Border radius:** Card corners, button corners
- **Shadows:** Card hover shadows, elevation patterns
- **Tags/Badges:** Pill-shaped tech tags on project cards

IMPORTANT: Document the Crator tokens but note that we will ADAPT them to Autoikigai's brand. We're keeping our dark theme (black bg, #00E0FF cyan accent, Bebas Neue font). We're copying the LAYOUT and STRUCTURE, not the exact colors/fonts.
