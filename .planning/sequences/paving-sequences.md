# 🛣️ Reactivation Sequences — Commercial Paving & Sealcoating

> These are the actual messages sent to your CLIENT'S dead leads (not to prospects).
> Customize `{Business Name}` and `{Service}` per client.

---

## SMS Sequence (4 Touches Over 7 Days)

### SMS 1 — Day 0 (The Opener)
```
Hi {Lead First Name}, this is {Business Name}. Quick question — 
are you still looking to get that paving/sealcoating work done? 
We had your info from a while back and wanted to check in. 
Reply YES if you're still interested!
```

### SMS 2 — Day 1 (The Value Add)
```
Hey {Lead First Name}, just following up from yesterday. 
We've got crew availability this {month} and could get you 
a refreshed quote if the old one expired. 
Want me to have someone reach out? 🛣️
```

### SMS 3 — Day 3 (The Nudge)
```
Hi {Lead First Name} — last check-in from {Business Name}. 
If you're still thinking about that driveway/parking lot project, 
we can squeeze you in before the season gets crazy. 
Just text back YES and we'll set it up.
```

### SMS 4 — Day 7 (The Breakup)
```
Hey {Lead First Name}, I'll stop bugging you 😊 
If you ever need paving or sealcoating, just text this number — 
{Business Name} will be here. Have a great week!
```

## Response Handling Rules

| Response | Action |
|----------|--------|
| "Yes" / "Interested" / "How much?" | Forward to client's team IMMEDIATELY. Include lead name, phone, and service interest. |
| "Not right now" / "Maybe later" | Tag as NURTURE. Re-contact in 30 days with a fresh message. |
| "STOP" / "Unsubscribe" / "Remove me" | Remove from ALL sequences immediately. Log for compliance. |
| "Wrong number" | Remove from sequences. Mark in system. |
| "Already got it done" | Remove from sequences. Mark as "service completed elsewhere." |
| No response after full sequence | Mark as EXHAUSTED. Do not re-contact for 90 days. |

## Timing Notes
- **Best SMS send times:** Tuesday-Thursday, 9AM-11AM and 2PM-4PM local time
- **Avoid:** Monday mornings, Friday afternoons, weekends
- **Seasonal priority:** March-June (pre-summer rush) and Sept-Oct (fall prep)
- **Max daily sends per client:** 50 leads/day to maintain deliverability
