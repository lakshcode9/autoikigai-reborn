# 🔥 Reactivation Sequences — Commercial Fire & Security

> These are the actual messages sent to your CLIENT'S dead leads.
> Customize `{Business Name}` and `{Service}` per client.
> Key angle: COMPLIANCE. These aren't optional — regulatory pressure does the selling.

---

## SMS Sequence (4 Touches Over 7 Days)

### SMS 1 — Day 0 (The Compliance Opener)
```
Hi {Lead First Name}, this is {Business Name}. We wanted to 
check in — we had your building on our schedule for a 
{fire alarm inspection / sprinkler service / panel upgrade}. 
Is that still something you need taken care of?
```

### SMS 2 — Day 1 (The Urgency)
```
Hey {Lead First Name}, just following up. A lot of buildings 
in {area} are getting their annual fire safety inspections 
updated right now. We've got a technician in your area this 
{week/month}. Want me to get you on the schedule? 🔥
```

### SMS 3 — Day 3 (The Risk Angle)
```
Hi {Lead First Name} — quick reminder from {Business Name}. 
If your fire safety systems haven't been serviced recently, 
it could affect your building's insurance and compliance status. 
We can do a quick check — just reply YES to get started.
```

### SMS 4 — Day 7 (The Breakup)
```
Hey {Lead First Name}, this is {Business Name}. 
I'll stop reaching out, but if you ever need fire alarm, 
sprinkler, or security system service, just text this 
number. Stay safe! 🏢
```

## Response Handling Rules

| Response | Action |
|----------|--------|
| "Yes" / "Schedule me" / "What's the cost?" | Forward to client's team IMMEDIATELY with building details. |
| "Already serviced" / "We switched providers" | Remove from sequence. Mark as "competitor retained." |
| "Not right now" / "Maybe next quarter" | Tag as NURTURE. Re-contact in 30 days timed to inspection cycles. |
| "STOP" / "Unsubscribe" | Remove immediately. Log for compliance. |
| "Wrong number" / "Don't manage that building" | Remove. Mark in system. |
| No response after full sequence | Mark as EXHAUSTED. Re-contact in 60 days (shorter cycle due to compliance urgency). |

## Timing Notes
- **Best SMS send times:** Tuesday-Thursday, 8AM-10AM (catch FMs at start of day)
- **Seasonal priority:** January (new year budgets), April-May (annual inspections), October (pre-holiday compliance)
- **Key angle:** Always frame as COMPLIANCE, not sales. "Your building needs this" > "We want your business"
- **Max daily sends per client:** 50 leads/day
