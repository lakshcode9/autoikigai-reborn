# 🌳 Reactivation Sequences — Arborist / Tree Care

> These are the actual messages sent to your CLIENT'S dead leads.
> Key angle: THE TREE IS STILL THERE. Seasonal urgency + safety.

---

## SMS Sequence (4 Touches Over 7 Days)

### SMS 1 — Day 0 (The Reminder)
```
Hi {Lead First Name}, this is {Business Name}. We gave you 
an estimate a while back for {tree removal / trimming / stump grinding}. 
Quick question — is that still something you want to get done? 
We've got crew availability this {month}. 🌳
```

### SMS 2 — Day 1 (The Seasonal Push)
```
Hey {Lead First Name}, just following up. With {storm season / 
winter / spring} coming up, now is actually the best time to 
take care of that tree work before things get crazy. 
Want us to refresh your quote?
```

### SMS 3 — Day 3 (The Neighborhood Angle)
```
Hi {Lead First Name} — we've got a crew working in {neighborhood / 
area} this week. If you still need that tree work done, we could 
fit you in while we're already there (saves on setup costs). 
Just reply YES! 🌲
```

### SMS 4 — Day 7 (The Breakup)
```
Hey {Lead First Name}, last text from me! If you ever need 
tree removal, trimming, or emergency work, just text 
{Business Name} at this number. We'll take care of you.
Have a great week! 🌿
```

## Response Handling Rules

| Response | Action |
|----------|--------|
| "Yes" / "Get me a quote" / "What's it cost now?" | Forward to client's team. Include service type and address if available. |
| "Already got it done" / "Used someone else" | Remove from sequence. Mark as completed. |
| "Maybe in spring/fall" | Tag with callback date. Re-contact 2 weeks before that season. |
| "STOP" | Remove immediately. |
| "Emergency — tree fell!" | URGENT forward to client. This is a high-value call. |
| No response after full sequence | Mark as EXHAUSTED. Re-contact in 90 days. |

## Timing Notes
- **Best SMS send times:** Tuesday-Thursday, 9AM-11AM and 2PM-4PM
- **Seasonal priority:**
  - **March-May:** Spring cleanup, pre-storm prep, HOA compliance
  - **August-September:** Pre-fall removal, storm damage prevention
  - **November-December:** Dormant season work, holiday lot clearing
- **Weather trigger:** After major storms, immediately contact ALL leads in affected areas with: "Hi {Name}, hope you're okay after the storm. If any trees on your property were damaged, we're prioritizing emergency calls this week. Need us to come take a look?"
- **Max daily sends per client:** 50 leads/day
